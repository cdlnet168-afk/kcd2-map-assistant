# 波西米亚手记 · KCD2 Map Assistant

《天国：拯救Ⅱ》的中文本地地图与探索笔记工具，适合硬核模式。覆盖特罗斯基与库滕贝格；数据离线使用，个人记录保存在自己的电脑。

## 使用

1. 安装 **Python 3.10 或以上版本**（标准库即可，无需 pip 安装）。
2. 下载 [完整程序包 kcd2-map-assistant-v0.2.0.zip](./kcd2-map-assistant-v0.2.0.zip) 并解压，进入 kcd2-map-assistant 文件夹，Windows 双击 launch.cmd。

   本仓库当前以完整源码压缩包交付；Code → Download ZIP 会再包一层，需要继续解压其中的程序ZIP。
3. 浏览器自动打开本机地址，通常为 http://127.0.0.1:8872/。若已运行则打开现有工具。
4. 其他系统可在项目目录运行 python3 server.py。不自动打开浏览器则使用 python3 server.py --no-browser。
5. 从页面“退出”按钮结束本地服务。

## 功能

- 两张中文地标地图、161条任务攻略记录及3583个社区点位。
- 草药、装备道具、藏宝探索、任务地点、住宿、炼金、修理、商店等分类与细分类。
- 中英文搜索、收藏、完成/收集状态、手动标记、位置和路线记录。
- 日月方位面板：24小时太阳粗略参考、分地图与日期的现场观测、朝向估算。
- JSON 导入导出；自定义地图会随导出备份一起保存。
- 点位聚合与列表分页。
- 旧笔记底图保留原任务接取区域和旧坐标；中文底图采用独立坐标。

## 数据精度

社区点位不是官方完整数据库，也未对使用者的当前客户端逐一实测。草药111条包含102个草药物品点与9处林中花园，不代表全部野生植物分布；可能位于容器或室内。任务地点可能是目标而不是接取NPC。物品所有权、门锁、高度和任务阶段需现场确认。

中文地标和分类为辅助译名，部分物品名称保留英文；不能称为完整官方汉化。

太阳方向是粗略模型，06点东、12点南、18点西不等于二代的实测日出日落表。月亮没有观测记录时显示未知；记录按地图和玩家维护的周目日期分开，同一时段仅匹配相差不超过30分钟的记录。

## 保存

所有个人数据在 data/，该目录不进入Git。服务仅监听127.0.0.1，无需游戏进程读取、账号或网络连接。首次运行使用干净清单。关闭前确认已保存；定期导出JSON备份。此压缩包不含个人笔记、上传图片或电脑专用路径。
