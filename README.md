# 波西米亚手记：天国拯救2 中文地图助手

**边玩游戏，边查地图、找任务和物品、写自己的探索笔记。支持特罗斯基和库滕贝格两张地图。**

这是在你电脑上运行的地图工具。需要先安装 Python；程序包已包含源码、地图和点位数据。适合 Windows 玩家，普通模式和硬核模式都可以作为参考。

## 第一次使用：照着这4步做

### 1. 下载程序

**[点击这里下载完整程序 ZIP](https://github.com/cdlnet168-afk/kcd2-map-assistant/raw/refs/heads/main/kcd2-map-assistant-v0.2.0.zip)**

文件名是 **kcd2-map-assistant-v0.2.0.zip**，约9MB。

如果浏览器打开了GitHub文件预览页，请点“Download raw file”（下载原始文件）。不要只下载README说明文件。

### 2. 安装 Python（只需安装一次）

打开 **[Python 官方 Windows 下载页面](https://www.python.org/downloads/windows/)**，选择适合自己电脑的稳定版安装程序。普通Windows电脑通常选择 **Windows installer (64-bit)**。

运行安装程序。若看到 **Add python.exe to PATH** 选项，请勾选，再完成安装。版本要求 **Python 3.10 或以上**；已经安装符合要求的版本可跳过这一步。无需安装其他Python库。

### 3. 解压，找到启动文件

右键刚下载的ZIP，选择 **“全部提取”/“解压到……”**，解压到一个固定文件夹。

打开解压后的 **kcd2-map-assistant** 文件夹，应该能看到：

- **launch.cmd** ← 双击这个文件启动（系统隐藏扩展名时，可能只显示launch）。
- server.py
- dist 文件夹

**不要在ZIP预览窗口里直接启动，也不要只把launch.cmd拖出来；这些文件和文件夹要放在一起。**

如果你用了GitHub绿色“Code → Download ZIP”，会下载整个仓库。先解压外层，再解压里面的 **kcd2-map-assistant-v0.2.0.zip**，直到看到launch.cmd。

### 4. 双击启动，开始使用

双击 **launch.cmd**，浏览器会自动打开地图。

看到“波西米亚手记”和地图，就启动成功了！网址通常是：

[http://127.0.0.1:8872/](http://127.0.0.1:8872/)

这个地址指的是你自己的电脑，不是公开网站。**每次使用先双击launch.cmd，再打开地图页面。**

## 打开以后怎么用

- **换地图**：点上方“特罗斯基”或“库滕堡”。
- **找任务、草药或装备**：点左侧分类，在搜索框输入中文或英文名称；还可以选择细分类。
- **看位置**：点击左侧结果或地图标记，查看详情。一个数字标记表示多个点重叠，点击可选择，放大可分开看。
- **移动地图**：按住鼠标拖动；滚轮放大缩小。“全图”恢复整张地图视图。
- **写笔记**：点“添加标记”，再点地图上的位置，填写名称和笔记；记录自动保存。
- **记当前位置**：点“我在这里”，再点地图位置。这是手动记录，请自己确认位置。
- **收藏或记录收集进度**：打开标记详情，点收藏，或把状态改为“已完成/已收集”。
- **辨别方位**：打开“日月方位”，查看粗略太阳参考，或记录自己观察到的太阳/月亮方位。
- **备份**：点“导出备份”，把下载的JSON保存好。换电脑可通过“导入”恢复。
- **退出**：确认页面显示已保存，点右上角“退出”。

自己的笔记会保存在程序旁边的 **data 文件夹**。关闭浏览器再打开，记录仍在；**移动程序时请连同data一起移动，更新前先导出备份**。

## 常见问题

**双击后一闪就关，或提示找不到Python？**  
重新检查Python是否安装完成。重新打开Windows终端，输入 python --version 或 py -3 --version，应该显示3.10或以上版本。若仍提示找不到命令，修复或重新安装Python并勾选添加到PATH。

**只打开网址，却提示“无法访问此网站”？**  
先双击launch.cmd启动程序；只收藏网址不会自动启动服务。若8872端口被其他程序占用，工具可能使用8873至8881，请使用启动后自动打开的地址。

**看到英文物品名，是出错了吗？**  
不是。地图地标和分类有中文，部分物品保留英文名称，可用英文原名搜索。

**怎么更新？**  
先在旧版本“导出备份”，把新版解压到另一个文件夹，启动新版后“导入”JSON。不要删除尚未备份的旧data文件夹。

**能在手机上双击运行吗？**  
这个包面向电脑，本地服务仅监听本机地址，不能直接当手机网页使用。

**Mac/Linux怎么启动？**  
本版本主要在Windows上验证。安装Python后，在解压目录运行 python3 server.py；若不自动打开浏览器，可运行 python3 server.py --no-browser，再打开终端显示的本机地址。

## 功能

- 两张中文地标地图、161条任务攻略记录及3583个社区点位。
- 草药、装备道具、藏宝探索、任务地点、住宿、炼金、修理、商店等分类与细分类。
- 中英文搜索、收藏、完成/收集状态、手动标记、位置和路线记录。
- 日月方位面板：24小时太阳粗略参考、分地图与日期的现场观测、朝向估算。
- JSON 导入导出；自定义地图会随导出备份一起保存。
- 点位聚合与列表分页。
- 旧笔记底图保留原任务接取区域和旧坐标；中文底图采用独立坐标。

## 数据精度

社区点位不是官方完整数据库，也未对使用者的当前客户端逐一实测。草药111条包含102个草药物品点与9处林中花园，不代表全部野生植物分布；可能位于容器或室内。任务地点可能是目标而不是接取NPC。物品所有权、门锁、高度和任务阶段需现场确认。

中文地标和分类为辅助译名，部分物品名称保留英文；不能称为完整官方汉化。

太阳方向是粗略模型，06点东、12点南、18点西不等于二代的实测日出日落表。月亮没有观测记录时显示未知；记录按地图和玩家维护的周目日期分开，同一时段仅匹配相差不超过30分钟的记录。

## 保存

所有个人数据在 data/，该目录不进入Git。服务仅监听127.0.0.1，无需游戏进程读取、账号或网络连接。首次运行使用干净清单。关闭前确认已保存；定期导出JSON备份。此压缩包不含个人笔记、上传图片或电脑专用路径。
